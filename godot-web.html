Playtest your Godot web game

Upload the Godot 4 web export, send players one link, and see how they played it.

Export

  • Project › Export › Web, from a GDScript project. Godot 4 can't export C# to the web yet.
  • Single-threaded (the default) and multi-threaded exports both work: Godot builds are served cross-origin isolated.
  • Zip the folder with index.html in it. Builds up to 100 MB unpacked.

Saves

Godot saves to user://, which is IndexedDB in a web build and not read by Betacade yet. Copy your progress into localStorage at each checkpoint, and Betacade shows how far each player got:

if OS.has_feature("web"):
    JavaScriptBridge.eval("localStorage.setItem('save', %s)" % JSON.stringify(JSON.stringify(progress)))

Without it you still get sessions, play time, errors and feedback. More in the game state guide.
