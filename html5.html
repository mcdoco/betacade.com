Playtest your HTML5 game

Plain HTML and JavaScript, or anything that exports to the web: Phaser, three.js, Babylon.js, PlayCanvas, Defold, GameMaker and the like.

Upload

  • Zip the folder with index.html in it, and upload it in the studio, or have your coding agent deploy it.
  • Builds up to 100 MB unpacked. Everything in a build is public: never put keys or passwords in it.

Saves

Keep the game's state in localStorage, as JSON under readable keys, and save often. Betacade reads it with no platform code in the game, so you see how far each player got:

localStorage.setItem("save", JSON.stringify({ level: 3, deaths: 12 }));
